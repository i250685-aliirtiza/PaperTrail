# PaperTrail

**PaperTrail - A Collaborative Document Explorer with Version Control**

- Course: CS2001 Data Structures, FAST NUCES Islamabad, Fall 2026
- Language: C++
- Application: Single-process, single-threaded, in-memory console program
- Team: Ali Irtiza, Abdul Rehman, Abdullah Khalil

## Purpose

PaperTrail is a collaborative document explorer with version control. This repository currently contains the project organization and documentation scaffold. All implementation will be written by the three student developers.

## Module ownership

- Ali Irtiza: Version Control Engine and shared ring queue
- Abdul Rehman: Search & Analysis Engine and shared hash map/exact sets
- Abdullah Khalil: Workspace & Document Engine, shared dynamic array/stable sort/stack
- Joint: Shared identity contracts, memory tracker, integration and testing

The official instructor project statement governs requirements.
