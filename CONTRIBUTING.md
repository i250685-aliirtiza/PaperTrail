# Contributing

## Ownership boundaries

Ali Irtiza owns the Version Control Engine. Abdul Rehman owns the Search & Analysis Engine. Abdullah Khalil owns the Workspace & Document Engine. Shared foundations follow the ownership recorded in docs/ownership.md. Integration and testing are shared.

## Feature branches

Use a feature branch named for the owning member and work area, such as ali/version-control or abdul/search-index.

## Code review

Reviewers should check ownership boundaries, documented contracts, deterministic behavior, memory ownership, exact output requirements, and the absence of warnings and errors.

## Authorship

Each member authors their own implementation.
